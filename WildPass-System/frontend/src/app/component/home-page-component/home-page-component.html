ברוכים הבאים

אוהבים בעלי חיים ומציעים טיפולים, אימוץ ושירותים קהילתיים במקצועיות ובחמלה.

המרכז נוסד מתוך תשוקה לאיכות חיים של בעלי החיים וניסיון של שנים בטיפול וטרינרי ושיקום. אנו פועלים כדי לוודא שכל חיה מקבלת את הטיפול הרפואי, התזונתי והרגשי שהיא זקוקה לו.

בצוותנו וטרינרים מוסמכים, מטפלים מוסמכים ומתנדבים מסורים. העבודה המשותפת מבטיחה תשתיות לאימוץ אחראי, מעקב לאחר האימוץ ותמיכה במצבי חירום.

מעבר לטיפול הישיר, אנו מקדמים חינוך קהילתי — סדנאות, ימי עיון ושיתופי פעולה עם בתי ספר ועמותות כדי להגביר מודעות ורווחה לבעלי החיים בסביבה.

נשמח לשתף פעולה כמתנדבים, תורמים או מאמצים — צרו קשר ונעזור למצוא את הדרך המתאימה לכם להשתתף.
